## 现在可以查询什么

两组条件可同时组合：

- 场况：场风、第几局、本场数、LuckyJ 及下家/对家/上家的持点范围和次位、自风、本局第几次 LuckyJ 切牌。
- 切牌：暗手牌包含或完全相同、摸入牌、切出牌、手切/摸切、本次是否宣言立直、以当前一步为结尾的连续切牌序列。

手牌计入本次摸牌，不包含副露；重复张数严格匹配。赤五可独立匹配，也可与普通五合并。分数与次位可切换“切牌前”和“本局开始”两种口径。切牌序号不是全桌巡目。

本次全量数据上的实际检索例子（切牌前口径）：南 4 局、LuckyJ 四位有 2,529 条；手持 `233m` 且切 `2m` 有 217 条；切 `0p` 即赤五筒有 321 条。它们只是具体筛选结果计数，不是战术标签。

详情保留当时可见的四家牌河、副露、已公开宝牌指示牌及分数；默认不暴露他家暗手牌或未来结算。原始 XML 和完整事件仍保留，下一阶段加特征可以从本地重建。

## 启动与边界

下载 Release 中的 `LuckyJ-phase1.zip`（134,174,276 字节，约 128 MiB），解压后进入 `LuckyJ` 文件夹：

```sh
python -m luckyj serve --data data
```

打开 `http://127.0.0.1:8000`。需要 Python 3.10+，运行程序无需第三方包、Node.js 或数据库服务。已有数据包不必重新下载及建库。

这是可本地运行的网页前端，尚未部署公开网站。没有加入向听、牌效、危险度、攻守判断、战术名称等第二阶段内容。
